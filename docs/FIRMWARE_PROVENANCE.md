# 固件来源与分析对象

本项目的静态研究以极米官方提供的 **NEW Z6X USB 强刷固件包**为依据，并结合一台相同系统版本设备的诊断报告和网络 ADB 实测。分析日期为 **2026-10-25**。使用本工具不要求重新下载或刷入固件；本次验证也没有通过刷机来开启 ADB。

## 官方获取位置

- [极米官网 NEW Z6X 型号页面（id=91）](https://shop.xgimi.com/host_list/91?name=NEW%20Z6X)
- [官网固件型号列表接口 allHost](https://xgimi-mall-gateway.xgimi.com/mall/firmware/allHost)
- [官网该型号版本接口 hostEdition/91](https://xgimi-mall-gateway.xgimi.com/mall/firmware/hostEdition/91)
- [官方 V12.15.180 固件下载直链](https://support.xgimi.net/the_top_secret/MSD848_ZM01/V12.15.180/XGIMI_IRONMAN_XH25L.bin)

这些是本次分析取得来源时的官方位置。官网页面、接口和下载链接以后可能调整；项目没有镜像或重新分发固件，也没有用其他型号固件替代该包。官方说明明确区分 **NEW Z6X 与普通 Z6X，不能互刷**。

### 设置应用存在后续更新

| 对象 | 版本 |
| --- | --- |
| 官方 BIN 中的 `com.android.newsettings` | 5.00.53 / versionCode 20220402 |
| 测试设备实际启用的同包应用 | 5.00.56 / versionCode 20220630，来自后装更新 |

因此，从官方 BIN 静态分析得出的设置菜单控制流属于 **5.00.53**，不能宣称已逐方法核实设备更新版 **5.00.56**。测试设备的 MiniTvFactory 版本号一致，但未单独拉取并比较其 APK 哈希。设置更新版未纳入本次官方 BIN 的静态分析范围。
