# 隐私与数据说明

## 网络

应用不申请 `INTERNET` 权限，不含广告、统计或联网 SDK，不主动上传诊断结果，也不向 GitHub 发送数据。电脑连接投影仪的网络 ADB 是固件的服务能力，不是本应用代为上传数据。

## 读取的数据

诊断会读取本机可见的 Android Build 信息、固件指纹、相关应用版本、ADB 属性、调试标记、USB 状态、部分系统组件与限制项。读取不到的值不会被自动解释成“关闭”或“没有”。

应用不读取个人媒体、通讯录、账号或电脑的 ADB 私钥。

## 本地保存

准备调试配置前，应用会将原始配置、board、incremental、固件 fingerprint 和保存时间写入应用私有数据，用于检查及恢复。该备份不随普通 APK 覆盖安装删除，但卸载或清数据会删除。

只有用户选择复制或导出时，诊断内容才进入剪贴板或本地 TXT 文件。导出公共下载目录时会申请存储权限；拒绝或写入失败时使用备用目录并显示位置。不使用导出也可检测及操作。

## 分享前检查

导出的日志可能包含设备信息、时间、文件路径和你后来补充的内容。发帖或提交 issue 前自行检查，按需删去设备标识、个人文件位置和网络地址。不要上传 APK 签名私钥、ADB 私钥、完整设备备份或未经许可的厂商文件。

## 系统侧的主机授权

本固件的新主机公钥流程可能自动授权，无标准确认弹窗。固件可能将主机公钥保存为后续信任依据；本应用不读取或删除它。恢复原始配置不等于撤销授权，也不保证运行中的 ADB 立即关闭。仅在可信局域网启用，使用后检查服务和连接状态。
