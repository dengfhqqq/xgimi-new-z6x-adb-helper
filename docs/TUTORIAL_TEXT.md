# 应用内教程文案

以下文案可直接用于原生文本教程页。按钮名称应与界面一致；教程可滚动、可用遥控器翻页。

## 开始前

本工具仅在 NEW Z6X、Android 8.0.0、ironman / v12.15.180 上验证。准备或恢复配置会核对完整固件 fingerprint，其他版本拒绝写入。

电脑与投影仪连接同一可信局域网。无需 USB 工程线。网络 ADB 成功不代表 USB ADB 可用，也不代表取得 root。

本固件会自动允许收到的新主机公钥，可能不弹 RSA 授权框。不要在公共网络开启，也不要将 5555 映射到互联网。

## 首次启用 · 1 / 检测

打开应用，等自动检测结束，再选择“刷新状态”。先确认设备支持，查看持久配置、调试标记、服务状态及端口。

persist.sys.usb.config 为 none 时继续准备配置。已是 adb 时不必重复准备；没有原始备份时，应用也不会虚构备份。

## 首次启用 · 2 / 准备配置

选择“准备调试配置（需重启）”，检查确认框的当前值 → adb，确认后等待回读。

应用会重新核对设备与状态，同步保存原始 none 备份，再请求写入。备份失败、状态变化或未知值都会停止。

必须看到持久值精确回读为 adb，才能继续。只显示“请求返回”不代表写入成功。失败时先保存报告。

## 首次启用 · 3 / 正常重启

确认持久值为 adb 后，自行正常重启投影仪。应用不会替你重启；退出应用再打开不算系统重启。

系统完全启动后重新打开应用并检测。已验证重启后 adb_enabled 变为 1，但 ADB 服务仍可能停止。sys 配置变成 mtp,adb 是固件自动行为，不证明 USB 已连接。

## 首次启用 · 4 / 启动服务

持久值为 adb、adb_enabled 为 1，而服务为 stopped 时，选择“启动 ADB 服务”，在确认框确认并等回读。

服务已经 running 就直接连接。单独启动服务不会代替准备配置和重启；初始调试标记为 0 时曾出现一直 unauthorized。

## 首次启用 · 5 / 电脑连接

安装 Android SDK Platform-Tools，在投影仪网络设置查看当前 IP。将“投影仪IP”替换为实际地址，执行：

adb connect 投影仪IP:5555
adb devices -l
adb -s 投影仪IP:5555 shell id

状态为 device，且指定目标的命令能执行，才算连接成功。已验证权限是 uid=2000(shell)，不是 root。应用显示 running 不能替代电脑实测。

## 以后使用

每次重启先检测。持久值 adb、调试标记 1：服务运行时直接连接；服务停止才点“启动 ADB 服务”，无需重复准备配置。

本次用完可点“停止 ADB 服务”。它只停止当前服务，不恢复持久配置、不删除主机密钥。电脑 adb disconnect 也只断开电脑连接。

## 恢复原始配置

保留应用数据，先保存当前报告，再选“恢复原始配置”。仅可恢复本应用保存的同设备原始 none；无备份不允许写入。

确认后等待持久值精确回读为 none，再正常重启并检测。必要时另行点“停止 ADB 服务”；恢复流程不会自动附加停止请求。

完整恢复与重启闭环尚未实测。恢复不清除主机密钥，不代表撤销授权，也不保证网络 ADB 立即关闭。卸载或清数据会丢失应用内备份。

## 故障判断

不支持或未知值：停止写入并保存报告，不绕过保护。

Connection refused：核对当前 IP、同一局域网和服务是否 running。

unauthorized：核对持久值 adb、调试标记 1、是否正常重启；本固件可能没有授权弹窗。

连接超时：检查访客网络、设备隔离、IP 变化和电脑网络。

USB DISCONNECTED：不影响继续验证网络 ADB；本项目没有证明 USB 工程线可用。

导出失败：查看备用保存位置，或复制诊断全文。公开分享前删去不希望公开的设备和网络信息。

## 关于工具

独立研究项目，非极米官方工具。应用无网络权限，不主动上传数据。打开和检测不写 ADB 配置；每次配置、启停操作均需要确认。只请求固定配置与服务操作，不刷机、不自动重启、不获取 root。
