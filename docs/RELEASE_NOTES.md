# Z6X ADB 助手 v1.6.0

适用于已验证的 NEW Z6X Android 8.0.0 / ironman / v12.15.180。不是普通 Z6X 通用工具。

- 原生横屏界面：状态概览、使用教程、诊断报告、关于与恢复。
- 内置八章离线教程，覆盖首次准备、正常重启、按需启动服务、电脑连接、后续使用、恢复与排错。
- 保留原包名和签名，可覆盖旧版并保留配置备份。先保存原始 none 基线，再执行固定写入与精确回读。
- 附官方分析包 `XGIMI_IRONMAN_XH25L.bin` 的下载地址、版本、大小、SHA-256 与实机更新差异。
- 明确声明：本项目全程由 AI 协助分析、编写、设计、编译与检查，用户配合实机操作和日志验证。
- 公开材料省略实际 IP、MAC、序列号、个人路径和原始设备日志；保留判断兼容性所需的固件信息。

构建、29 项策略测试、签名/对齐/完整性及实机界面检查通过。恢复预检到达确认框后取消；没有执行完整恢复。本轮没有重新修改调试配置或启停服务。

网络 ADB 已验证，普通 shell 权限；USB ADB、其他固件与完整恢复仍未验证。此固件可能自动允许新主机公钥，请在可信局域网使用。

下载 APK 后可用同目录 SHA256SUMS 校验。自行编译或 CI 临时签名的 APK 不能直接覆盖本发布包；卸载或清数据会丢失应用内原始配置备份。
